# Load Testing with k6, Prometheus, and Grafana

This project aims to perform **load testing** using **k6**, collect the results with **Prometheus**, and visualize them in **Grafana**. By running **k6** locally, Prometheus collects the data, and Grafana is used to visualize the results.

## Project Components

1. **k6**: The tool used to run load tests and generate the test data.
2. **Prometheus**: Collects and stores metrics generated by k6.
3. **Grafana**: Visualizes the collected data from Prometheus.

## Requirements

- **Docker** (Optional, for containerized setup)
- **Prometheus** (For data collection and storage)
- **Grafana** (For data visualization)
- **k6** (For load testing)

### Installation Steps

#### 1. Install k6

To install k6, use the following command:

```bash
# Install via Homebrew
brew install k6
```

#### 2. Install Prometheus

To install Prometheus, use the following command:

```bash
# Install via Homebrew
brew install prometheus
```

Make sure to configure **`prometheus.yml`** with the correct port settings.

#### 3. Install Grafana

To install Grafana, use the following command:

```bash
# Install via Homebrew
brew install grafana
```

By default, Grafana runs on port **3000**.

#### 4. Docker (Optional) Setup

Alternatively, you can use **Docker** to run Prometheus, Grafana, and k6 containers. Here's an example `docker-compose.yml` file:

```yaml
version: '3'
services:
  prometheus:
    image: prom/prometheus
    container_name: prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
  grafana:
    image: grafana/grafana
    container_name: grafana
    ports:
      - "3000:3000"
    environment:
      GF_SECURITY_ADMIN_PASSWORD: "admin"
    depends_on:
      - prometheus
```

#### 5. Prometheus Configuration

Configure the **`prometheus.yml`** file as follows:

```yaml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  # Scrape Prometheus itself
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  # Scrape k6 metrics
  - job_name: 'k6'
    metrics_path: '/metrics'
    static_configs:
      - targets: ['localhost:6565']

# Remote write configuration
remote_write:
  - url: "http://localhost:9090/api/v1/write"
```

#### 6. Run k6 Test

To start the k6 test, run the following command:

```bash
k6 run --out experimental-prometheus-rw=http://localhost:9090/api/v1/write test-script.js
```

Here, **`test-script.js`** is the k6 test script you want to execute.

#### 7. Configure Grafana Dashboard

After logging into Grafana (**default username and password: `admin/admin`**), add **Prometheus** as a data source:

1. Log into Grafana.
2. Go to **Configuration > Data Sources**.
3. Select **Prometheus** and set the URL as **`http://prometheus:9090`** or **`http://localhost:9090`**.
4. Click **Save & Test**.

To visualize the metrics from k6, create a new dashboard in Grafana and use the following queries:

- **Total HTTP Requests**:
  ```promql
  sum(k6_http_reqs) by (method)
  ```

- **Failed HTTP Requests**:
  ```promql
  sum(k6_http_req_failed) by (method)
  ```

- **Request Duration (http_req_duration)**:
  ```promql
  avg(k6_http_req_duration) by (method)
  ```

#### 8. Verify Prometheus and Grafana

- Access Prometheus at **`http://localhost:9090`**.
- Access Grafana at **`http://localhost:3000`**.

### Test Results

- In Grafana, you can visualize the **success**, **failure**, and **response times** of HTTP requests made during the k6 load tests.
- Prometheus will store the collected test data and provide it to Grafana for visualization.

---

## Troubleshooting

- **k6 data not reaching Prometheus**: Ensure that the **`remote_write`** URL is correctly configured, and that you're running k6 with the right output flag (`--out experimental-prometheus-rw`).
- **No data in Grafana dashboard**: Double-check that **Prometheus** is correctly configured as the data source in **Grafana**, and that you're using the correct Prometheus queries to fetch k6 metrics.
